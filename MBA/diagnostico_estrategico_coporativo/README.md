# Infografías interactivas

Este repositorio contiene infografías interactivas en HTML publicadas con GitHub Pages.

## Estructura

- `index.html` → página principal
- `/infografias/` → infografías individuales
- `/assets/` → recursos compartidos (CSS, JS, imágenes)

## Cómo añadir una nueva infografía

1. Crear un nuevo archivo HTML dentro de `/infografias/`
2. Copiar la plantilla base
3. Ajustar el contenido y el título
4. Subir cambios al repositorio

## Publicación

El sitio se publica automáticamente mediante GitHub Pages.
